# Chinese with Leo — сайт

Веб-версия Telegram Mini App [Chinese_byLeo](https://github.com/Fabu1ous1/Chinese_byLeo): китайский с нуля до HSK4.

- **Карточки** — ~1200 слов HSK1–HSK4: иероглиф, пиньинь, тон, перевод и пример, озвучка.
- **Тест** — два режима (汉 → RU и RU → 汉), урок или весь уровень, счёт и серия.
- **Грамматика** — 50 тем с формулами, примерами (с озвучкой) и проверочным вопросом.
- **Словарь** — поиск по иероглифам, пиньиню без тонов и по-русски, фильтры по уровню.
- Светлая/тёмная тема, горячие клавиши, адаптив под телефон.
- Прогресс хранится в `localStorage` (тот же ключ `chinese_progress`, что и в Mini App), можно выгрузить/загрузить файлом.

Чистая статика без сборки и зависимостей:

```
index.html       — разметка
css/style.css    — стили
js/data.js       — слова и грамматика (перенесены из Mini App)
js/app.js        — логика
```

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация

**GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)`.

**Vercel / Netlify:** импортировать репозиторий, фреймворк — *Other*, без команды сборки.

## Ссылка на бота

В `js/app.js` укажи адрес бота — появятся кнопки «Бот в Telegram»:

```js
const CONFIG = {
  telegramUrl: "https://t.me/your_bot",
};
```
